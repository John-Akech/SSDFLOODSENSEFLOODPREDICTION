2. Description of Service

FloodSense provides:

  • Flood Predictions: AI-powered forecasts using Sentinel-1 SAR, CHIRPS rainfall, SRTM elevation, and WorldPop data, processed through Random Forest and Temporal Convolutional Network models
  • Early Warning Alerts: Real-time flood notifications via Web Push API
  • GIS Recommendations: Dyke placement guidance for flood mitigation infrastructure
  • Community Feedback: Tools for reporting flood events and system usability

⚠️ Important Disclaimer

FloodSense is a research prototype and should not be used as the sole basis for life-safety decisions. Predictions are probabilistic and may contain errors. Always follow official government warnings and evacuation orders from authorities such as OCHA, WFP, and local disaster management agencies.
